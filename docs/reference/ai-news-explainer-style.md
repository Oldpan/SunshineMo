# 参考风格：「产品页讲解」：一个母版 + 随内容切换的风格插曲

2026-11-10 拆了 Drive `reference/` 根目录下新增的 22 个视频：20 条编号的 AI 新闻讲解（`01_…` 到 `20_…`，每条配一张封面）、1 条 3:4 竖版的 KV Cache 图解、1 条 25 秒的 Kimi 生成小片（账号「郊游」）。
视频本身只在 Drive，不进 git。`比特新语-小红书爆款视频/` 子目录是上一轮拆的，见 [`vibe-knowledge-style.md`](vibe-knowledge-style.md)，这里不重复。

## 一句话

整条片子是同一个「产品页」母版（浅底、白卡片、一个强调色、底部黑底字幕条），每隔 20–60 秒换一次画风「插曲」：像素游戏、美漫波普、螺旋笔记本、蓝图、深色控制台、黑板、牛皮纸、玻璃渐变卡……
每个插曲只在内容适合它的时候出现，用的还是母版的小标题和大标题字体，所以换了画风仍然是同一条片子。
这就是我们要的「讲解篇按内容进程灵活切风格」（见记忆 per-scene-style-mix）的现成样板。

## 母版：产品页舞台

画布 1920×1080，30 fps。每个场景讲一个点，几乎都是同一个版式，随旁白一块一块「长」出来。

| 项 | 做法 |
|---|---|
| 底 | 一屏一个浅色：奶油、淡蓝灰、薰衣草、薄荷、粉彩渐变。每个视频选一个强调色，大标题里 1–2 个关键词染成它。 |
| 小标题 | 左上一行等宽小字：章节号 + 英文大写，如 `03 · EVENT-DRIVEN`、`RETHINKING THE PURPOSE OF CODE REVIEW`；右上有时放小标签或进度点。 |
| 大标题 | 紧挨着一行粗黑体，一个问句或结论（「审查该问什么？」「从一道闸门，到拼写检查」），关键词染强调色。 |
| 卡片 | 白底圆角、极轻的阴影，顶部可带三色窗口点。三种状态：未出场（浅灰占位条）、已读完（变淡）、当前（强调色描边 + 填入内容）。被推翻的旧说法用删除线 + 一个黑色小标签「不精确的指标」。 |
| 构建节奏 | 每 2–4 秒长出一块：占位灰条 → 文字填入 → 旧卡片变淡、新卡片亮起 → 箭头连线。一个场景 15–40 秒，只有 9–28 次硬切，全靠场景内这些微变化让画面不静止。 |
| 图形 | 线图用细线 + 红色高亮点；流程用圆点串线；柱条用强调色一根、其余灰；仪表盘、环形进度、数字滚动；真实界面截图缩小放进卡片，旁边用红框圈出重点。 |
| 字幕 | 底部居中的一行黑底（约 85% 不透明）圆角小条，白色粗黑体，一句不超过 25–28 个字；换句时轻微淡入。画面里自己造的界面都要盖「示意」。 |
| 转场 | 同一风格内部是卡片位移 / 淡入。切到暗色插曲时，新画面从右侧滑过来盖住旧画面（边缘一道竖线），不用溶解。 |
| 声音 | 一个人声配音（中等偏快，听感约 5–6 字 / 秒，是模型转写估算），部分视频（17 等）垫一层轻快电子底乐，08 / 20 听不到底乐。成片平均响度约 −16.5 dB，AAC 48 kHz 立体声。无明显点击 / 嗖声类音效。 |
| 开头 | 前 5 秒：产品名大字（可用渐变字标）+ 三四个标签 + 一个会动的界面。不先讲背景。 |
| 结尾 | 「以上内容来自 …」卡：来源账号、官网、日期，按重要程度排。 |

## 风格插曲目录

每个插曲都有固定的「什么时候用」。编号是 `video/series/explainer/shared/scene-styles.yaml` 里的 id，分场候选板直接读这份清单。

### 1. `pixel` 像素游戏关卡

整屏深紫 / 深蓝底，像素字，左上「第几关」横幅，右上计分或回合牌（`ROUND 00 → 48`，滚动翻页）。元素：两个像素机器人、夜景城市天际线、问号解锁块（`? → LOCKED → 亮起`）、平台跳跃、世界地图节点连线、额度进度条、「RESULTS BEFORE / AFTER」表。
- 用在：循环和迭代（来回审了 48 轮）、规则一条条解锁、额度和限制、多个角色接力、前后对比结果。
- 做法：全部整数像素，按帧「抖」半步（`snap`）；数字用等宽像素体翻转；解锁块一块块亮起，每亮一块配一句旁白。
- 出现：01、03、05、06、08、09、10、11、14、15、16、17、18、20。**最常用的插曲**。
- 我们的套件：`shared/pixelplay.tsx`（`PixelStage`、`LevelBanner`、`Hearts`、`PixelWipe`），引擎自带 `pixel` 画风。

### 2. `comic` 美漫波普

蓝 / 黄半调圆点底（`#35C5F1` 圆点、奶油面板），4–6 px 黑色粗描边，错位硬阴影，放射星爆（`有了 Projects!`），大气泡，汗滴、手指、角色漫画脸。
- 用在：痛点和崩溃时刻、社区吐槽、产品突然出现、「问题就在这」。情绪比信息重，一次 8–15 秒。
- 做法：星爆放大弹出后轻微旋转；气泡从角色嘴边长出；红色手写印章斜盖在图上。
- 出现：07、09、10、11、12。
- 我们的套件：新增 `shared/comicpop.tsx`。

### 3. `notebook` 螺旋笔记本

深灰底桌面，一本方格纸笔记本，顶部一排螺旋环，右侧彩色索引贴，绿 / 黄便利贴，红笔圈出的数字和手写批注，右上角 `FIG 4` 标签，旁边一支铅笔。
- 用在：引用原文的图表和实验数据、「作者说」的段落、需要圈重点的数字。
- 做法：线图先画轴，再逐点出现，红笔圈是一笔画出来的（`stroke-dashoffset`）。
- 出现：05、07、13。
- 我们的套件：新增 `shared/notebook.tsx`（`NotebookBg`、`Sticky`、`RedCircle`、`FigTab`）。

### 4. `blueprint` 蓝图

深蓝底 + 白细线网格，白色细框线，右上角图纸标题栏，尺寸标注线，红色用来标注问题。
- 用在：规格、API 参数、安全设计图、步骤、曲线图的坐标说明。
- 出现：01、03、04、19。
- 我们的套件：`shared/stylemix.tsx` 的 `BlueprintBg` / `BpBox` / `Draw`。

### 5. `console` 暗色控制台 / LED 记分牌

深色底，等宽字，终端窗口（审查窗口、日志）、LED 七段数字（`1ST 56%`）、CRT 显示器外壳（`WATCHDOG`）。
- 用在：代码和日志、实时监控、占比和排名、工程师反馈引用。
- 出现：02、05、08、09、19。
- 我们的套件：`shared/console.tsx`、`stylemix.tsx` 的 `TermBg` / `TermWin`。

### 6. `chalk` 黑板粉笔

深灰绿黑板，木框，粉笔字逐笔写出（有轻微粉笔灰和不均匀笔迹），底部粉笔槽。
- 用在：从零推导一个概念、层层追问（Q1 → 是 / 否 → 结论）、「先看它是做什么的」。
- 出现：20。
- 我们的套件：新增 `shared/notebook.tsx` 里的 `ChalkBg` / `ChalkText`（和白板 `shared/whiteboard.tsx` 是一对，一个白底马克笔，一个黑底粉笔）。

### 7. `kraft` 牛皮纸 / 软木板拼贴

牛皮纸或软木底，胶带、图钉、斜着贴的卡片、红色印章（「出现」「调优」）、格子布、便签，卡片带轻微旋转和落地阴影。
- 用在：证据板、一组案例、成绩单、三条经验、产品版本和价位。
- 出现：04、13、14、16、17、20。
- 我们的套件：`shared/stylemix.tsx` 的 `CorkBg` / `Note` / `Stamp` / `DossierBg`。

### 8. `glass` 渐变玻璃卡

粉紫蓝渐变底，浮动的半透明球，圆角玻璃卡（背景模糊、一圈白描边），卡里放产品图、质量档位滑块、数字环。
- 用在：产品功能、模型对比、版本档位、「两个新模型」这类并列介绍。
- 出现：01、10、11、12。
- 我们的套件：新增 `shared/glass.tsx`。

### 9. `poster` 电影感大字海报

整屏一张氛围图（水墨山、星空、渐变）压暗，几组超大数字（`3T`、`1M`）分居两侧，中间产品字标。或者纯白底 + 超大粗黑体字标 + 一条副标。
- 用在：开场、章节首页、「一个数字撑起一页」（`DECISIONS 03`、`DATA CONTROLS`）。
- 出现：01、03、13、14、15。
- 我们的套件：`shared/evidence.tsx` 的大字版式可借；新增的 `prodpage.tsx` 里 `Poster` 提供底纹和数字布局。

### 10. `mascot` 角色陪看

一个固定角色待在画面角落，按内容换表情和动作：DeepSeek 小鲸鱼、Claude 小螃蟹、Grok 黑色团子、Dot 的橙色 3D 毛绒球（戴小礼帽）。
- 用在：贯穿整条视频当「引路人」，疑问时冒问号、出结论时蹦一下。
- 做法：角色素材用千问图像模型（见记忆 dashscope-image-models）做一套姿势，抠图后放角落，约 10% 画面。别拿别人品牌的角色。
- 我们的套件：`shared/pixelplay.tsx` 的 `Mascot` 和 `shared/gameshow.tsx` 的 `Bean` 可借用。

### 11. `crayon` 蜡笔手绘

淡紫纸底，蜡笔涂抹的桌子、杯子、粉色小团子，粗糙描边，涂不满的色块。
- 用在：温柔的人情场景（关心的消息、健康问题）、需要把「冷技术」拉回生活的一段。
- 出现：06（线稿）、18。
- 我们的套件：引擎自带 `crayon` 画风。

### 12. `datajournal` 数据新闻图表

米色底，红 / 蓝 / 绿数据色，细线折线加区间带，右侧大号数字对比（`21% → 14%`），蓝色注释气泡，每张图左上一行小标题（`FIGURE 2`）。
- 用在：研究报告里的曲线、占比、前后变化。
- 出现：07、09、12。
- 我们的套件：`shared/stylemix.tsx` 的 `DataBg`，数字滚动见 `claudeblog.tsx`。

### 13. `iso` 等距 / 线路图

白底紫色等距方块（GPU 方阵、办公室、传送带），或地铁式彩色线路图（项目 → 协调者 → 多条线程）。
- 用在：系统架构、数据流、并行线程。
- 出现：02、11、kv_cache。
- 我们的套件：`shared/iso/`（等距）；线路图可用 `Draw` 路径。

### 14. `ranking` 倒数榜单

左上巨大的名次徽章（`第 20 名`），名次越小徽章越亮、底色逐名更换，五星「大胆指数」，每条一页一个用法，全片 20 → 1。
- 用在：「N 个用法 / 案例 / 坑」类，一条一页，天然有悬念。
- 出现：18。
- 我们的套件：新增 `prodpage.tsx` 的 `RankBadge`。

## 一个视频怎么混

- 母版占大约 60–70%，插曲 3–6 个，每个 12–40 秒。第一个插曲别早于第 40 秒。
- 同一种插曲不连着用两次；两个插曲之间至少隔一个母版场景。
- 插曲放在这些地方：规则 / 循环段（`pixel`）、情绪和痛点（`comic`）、引用原文数据（`notebook` / `datajournal`）、规格和参数（`blueprint`）、代码和日志（`console`）、证据 / 案例堆（`kraft`）。
- 每个插曲内保留母版的小标题和大标题排法，只换底、卡片质感和图形语言。
- 插曲开头用一个转场（右侧滑入或像素擦除），结尾回到母版时用淡入，避免和母版内部的小动画混在一起。
- 每个视频只选一个强调色；章节色（10、13 号那种每章换粉彩）只用在背景，不换强调色。

## 3:4 竖版：KV Cache 图解

`聊聊模型侧怎么优化 KV Cache.mp4`，720×960，4:17，男声配音，无底乐，响度 −13 dB（比横版响）。小红书笔记的 3:4。

- 纯白底，画面上 2/3 是图，下 1/3 一行黑色无底字幕（不加黑条）。
- 只有两个颜色：紫色（方块、token 条）+ 橙色（注意力弧线、关键数字）。
- 一个例句贯穿：「猫把杯子推下了桌子，它……」，token 条一字一格，注意力弧线上标 40% / 36%。
- 数字开场：`2.6 TB`、`33 × H100`，再逐步压缩到 `12 MB`；每个优化方案（MHA → GQA → MLA → 滑窗）都画成同一幅图的变形，而不是换图。

## 25 秒小片：靛蓝木刻星夜

`Kimi_K3.1_Pro_小红书笔记.mp4`，1280×720，25 秒，纯管弦乐配乐（前 9 秒急促，后面舒展），账号「郊游」。
大概率是代码生成的画面：点刻月亮、青海波纹、扫描线纸面和细密排线都是程序化纹理。

- 一个黑色小圆团子（两只眼睛）一路旅行，每 2–3 秒换一景：月面、拱桥、图书馆长廊、夜海上的白浪小路、沙漠里的飞鸟、枯树、发光的星球边缘。

## 不要照搬的

- 参考里的 UI 是别人产品的真实界面或高保真复刻。我们不复制品牌图标、字标、吉祥物，用「通用产品页」的形状和我们自己的角色；自己编的界面一律盖「示意」。
