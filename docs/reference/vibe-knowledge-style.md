## 一句话

没有配音。电子乐 + 屏幕字幕，2 分 40 秒讲透一个有名字的概念，最后落到观众自己的生活。
画面克制：深色底、一束光、一个物件贯穿全片。

## 结构（6 条都一样）

| 段落 | 时间 | 内容 |
|---|---|---|
| 冷开场 | 0–17 s | 一个具体、反常的场景，4–6 句字幕，以问题收尾 |
| 标题卡 | 17–22 s | 大号发光衬线中文标题 + 字距拉开的英文小字（OCCAM'S RAZOR）+ 一句设问 |
| 机制 | 22–60 s | 经典实验或历史，开句「年份 + 人名」，数据动画讲清楚 |
| 递进 | 60–110 s | 第二、三个案例推广规律；插一张名言卡（人名 + 年份 + 原文） |
| 落到你身上 | 110–140 s | 聊天框、地铁门、差 1 分的分数线、人生时间轴 |
| 回扣 + 金句 | 140–165 s | 回到开场画面；对仗两句收尾；标题卡 + 极小字参考文献 |

## 节奏

- 约 60 句字幕，每句 2.5–3 s、十几个字；全片 800–1000 字。
- 很少硬切（银牌的眼泪 160 s 只有约 12 处大的画面变化）。同一物件变形、推近、加标注来换「镜头」。
- 锚物件：开场引入、全片复用、结尾回扣（领奖台、斑马线、赛艇小湾、「到家了吗？」气泡、落灰的房间、大号 37%）。

## 画面

- 近黑深蓝底 + 暗角；主体被聚光或自发光照亮，留大片空白。
- 每条一个暖色（金 / 琥珀 / 橙）+ 一个冷色（蓝 / 青 / 绿），负面用红，其余灰白。
- 元素：发光线条小人、粒子（灰尘、硬币、神经元、星点）、细线图表带刻度、仿真界面（航班屏、聊天界面、分数、输入框）、偶尔软阴影 3D 物件。
- 研究报告感的小字：中文名下配英文 / 学名，分段编号 01 / 02 / 03，数字滚动计数。
- 不用：bloom 堆叠、频谱条、故障切片、常驻色差。

## 字幕

- 衬线体（宋体类）白字；每句 1–2 个关键词上色。
- 逐字淡入。
- 位置随画面：叙事在底部居中；图表占底部时移到顶部；金句单独居中放大。

## 声音

- 无旁白（语音识别全空，音频模型确认纯器乐）。
- 电子嘻哈 / trap / lo-fi：钢琴 + 合成器，80–140 BPM，偏忧郁或紧张。
- 少量音效卡画面变化：嗖声、叮声、心跳、打字声。平均响度约 −16 dB。

## 封面

参考里没有单独封面；第一帧本身就是完整醒目的构图 + 一句字幕。我们照旧出 16:9 和 3:4 两张，用第一帧或标题卡的构图。

## 选题公式

有中英文名字的硬概念 × 一个经典实验或历史故事 × 一种人人有过的情绪（遗憾、内耗、等消息、感情变淡）。
避开已经被讲烂的：熵增、囚徒困境、墨菲定律。我们的差异化是 AI / 计算机概念讲生活（探索与利用、过拟合、局部最优、幻觉、死锁……）。

## 起名

6 条里 5 条不用术语当标题，只取片子里的一个画面、物件或数字，2–5 个字：
趋光（光遗传学）、银牌的眼泪（反事实思维）、37% 法则（最优停止）、剃刀（奥卡姆剃刀）、刷分的捷径（reward hacking）。
只有「熵增」直接用术语，而这个词本来就火。术语缩成标题卡上的小字（OCCAM'S RAZOR），标题下面配一句设问。
点赞最高的三条分别是一个画面、一个反常的情绪场景、一个具体数字。样本只有 6 条，点赞也跟选题有关，当规律用，不当证据。

## 写脚本前的检查清单

- [ ] 标题是片子里的一个画面 / 物件 / 数字，不是课本术语；术语放小字

- [ ] 概念有中英文名，能写成一张标题卡
- [ ] 冷开场是一个具体场景，不是定义；17 s 内抛出问题
- [ ] 至少一个「年份 + 人名」的经典案例，年份和结论查过原文
- [ ] 一个锚物件贯穿全片，结尾回扣
- [ ] 有一段落到观众日常的画面（聊天、通勤、考试、关系）
- [ ] 收尾是对仗两句，片尾列参考文献
- [ ] 一句字幕 ≤ 20 字，每句 1–2 个高亮词
- [ ] 全片只用一个暖色 + 一个冷色
