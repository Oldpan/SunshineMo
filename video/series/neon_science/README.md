# neon_science · 霓虹星云科普

一句话定位：把一篇心理学或科学研究讲成 2–4 分钟的 vibe 短片，节奏跟着电子乐走。没有配音，信息全靠字幕和图形。

## 视觉规范

- **背景**：SkSL 星云 shader（fbm 域扭曲），384×216 渲染后放大，加视差星点和缓慢漂移的光斑。
- **配色**：每个段落用一套配色，`style.PALETTES` 里有九套可选：
  - 夜（night）
  - 焦虑（anxious）
  - 实验室（lab）
  - 洋红高潮（magenta_drop）
  - 琥珀回忆（amber）
  - 青红对立（teal_red）
  - 紫色高潮（violet_drop）
  - 冷静（cool）
  - 暖色收尾（warm_end）

  高潮段的配色瞬切，其余段落 1.6 秒渐变过去。
- **强调色**：`PINK` 代表"对方 / 真实"，`CYAN` 代表"你 / 以为"，`GOLD` 代表"差距 / 结论"，`MINT` 用作辅助。
- **字幕**：中文用文泉驿正黑，英文和数字用 Inter，像素字用 unifont。一个镜头只用一种主样式，各种样式轮着用。可选样式在 `core/gfx.py`：
  - 打字机
  - 逐字浮现
  - 弹跳
  - 故障
  - 描边扫光
  - 竖排
  - 像素
  - 粒子成字
  - 富文本高亮
- **特效**：全部挂在音乐事件上：
  - 冲击和 drop：冲击波加闪白
  - 拍手：圆环
  - 高潮段的底鼓：火花和速度线
  - 全程：底部频谱条
  - 段落切换：故障切片
  - 镜头里可以手动加标题光条
- **后期**：
  - bloom 只给真正的高光（阈值 2.2x−1.25，强度 0.35，鼓点时加 0.3）。
  - 色差只在鼓点上出现，用 `x.chroma` 控制。
  - 颗粒 3。
  - 内容层下面垫一层暗晕（DropShadow 0.8）。
- **可读性红线**（v1 的教训）：画面不能像蒙了一层雾。字幕 glow 透明度 ≤ 0.5，不要有常驻色差，字幕下面要有暗底。

## 音乐配方（`template/music.py` 是缩小版）

- **速度与和声**：100 BPM，D 小调九和弦。主歌走 Dm9 → Bb9 → F9 → C69，副歌走 Bb9 → C69 → Am7 → Dm9。
- **结构**：引子 8 → 主歌 8 → 铺垫 8 → 高潮 8 → 间奏 8 → 铺垫 8 → 高潮 8 → 律动段 8 → 尾声 10 小节。
- **引子**：pad 渐亮，钟声提出"问题"动机。
- **铺垫**：军鼓滚奏加扫频 riser，最后一拍全体静音。
- **高潮**：supersaw、四拍底鼓、拍手、反拍开镲、sub 和八度贝斯、琶音、主旋律。
- **间奏**：电钢琴加秒针。
- **尾声**：钟声给出"回答"动机，落在主和弦上。
- **混音**：sidechain、ping-pong 延迟、代码生成的卷积混响；最后做软削波并淡出。

## 叙事套路

1. 用一个日常场景开场，制造悬念，比如"对方正在输入…"。
2. 把观众脑子里的念头摆出来，再推成负面漩涡。
3. 讲实验设计。
4. 第一个高潮给出核心数字。
5. 讲纵向数据和机制。
6. 第二个高潮讲复现研究和中国人的生活场景。
7. 给出三条建议。
8. 结尾回扣开场，用一句安慰收尾，片尾放参考文献。

## 封面

16:9 和 3:4 各一张，见 `template/cover.py`：
- 左侧或上方依次放钩子问题、渐变大标题、结论句（关键词粉色）、字距拉开的英文标题。
- 另一侧放核心数据图或聊天气泡。
- 数字标签不要和虚线、光条重叠。

## 新开一集

```bash
cd video/series/neon_science/episodes/<name>
python3 music.py && python3 render.py --still 3 8 13 && python3 render.py --range 0 8 --fps 30
```
