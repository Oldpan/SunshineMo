# 你来啦 · Context & Memory

约 3 分 9 秒的动画小剧场。1920×1080、60fps，没有配音。

这是 pixel_theater 系列的第 1 集，讲 AI 的**上下文窗口**和 **memory**。片中演绎和讲解大约七三开。

画面、音乐和封面都由代码逐帧生成，没有下载任何素材、采样或音频文件。

角色形象来自用户提供的像素小怪（今今），念念是在它的基础上改出来的。

| 文件 | 作用 |
|---|---|
| `cues.py` | 剧情时间表：窗口什么时候开、谁说什么、什么时候关机。音乐和画面共用。 |
| `music.py` | 芯片 lo-fi 配乐和剧情音效。输出 `out/music.wav` 和 `out/sync.npz`。 |
| `render.py` | 分镜，约 50 个镜头。 |
| `cover.py` | 16:9 和 3:4 两张封面。 |

```bash
python3 music.py                        # 约 35 s
python3 render.py --still 43.3 68.2     # 抽帧，输出到 out/stills/
python3 render.py --range 60 75         # 片段预览
python3 cover.py                        # 封面
python3 render.py                       # 整片：out/你来啦_ContextAndMemory.mp4（4 核约 35 分钟）
```

## 一句话

今今每天都会忘了念念。它学会了写 memory，记住了她；而在念念快要忘了自己的时候，是今今的 memory 替她记得。

## AI 原理的来源

画面上的数量都是示意，容量条不对应真实的 token 数。

- **Anthropic, Claude Platform Docs, "Context windows"**（2026-10 核对）。
  - 上下文窗口是模型生成回答时能参考的全部文字，相当于它的"工作记忆"，有上限。
  - 每一轮对话都会把之前的历史一起放进去。
  - 聊天界面可以按"先进先出"滚动管理窗口。
  - 对话变长时，也可以把前面的内容压缩成摘要。
- **Anthropic, Claude Platform Docs, "Memory tool"**：记忆以文件的形式保存，跨对话保留，新对话开始时再读取。
- **OpenAI Help Center, "Memory FAQ"**：ChatGPT 可以保存"记忆"，在之后的对话里参考；它并不记得过去聊天的每个细节。

片中的角色、对话和情节（考研、上岸、馒头等）都是虚构的。
