# 我不知道 · Hallucination

约 2 分 52 秒的动画小剧场，1920×1080、60fps，没有配音。

- **系列位置**：pixel_theater 系列第 2 集。
- **知识点**：AI 的**幻觉**，以及怎样减少幻觉。演绎和讲解大约七三开。
- **画风**：雨夜侦探（noir）。每集换一种画风，第 1 集是星夜小屏。
- **制作**：画面、音乐和封面都由代码逐帧生成，没有下载任何素材、采样或音频文件。

| 文件 | 作用 |
|---|---|
| `cues.py` | 剧情时间表，`music.py` 和 `render.py` 共用。包括：谁说什么；哪个镜头用什么转场；打字机字幕、印章、闪电、线索卡掉落、证据上墙的时间。 |
| `scene.py` | 本集的画风件：<br>· 配色：`NOIR` 四套。<br>· 场景：窗外雨夜城市、侦探办公室、软木板。<br>· 光与动态：百叶窗光带、窗上的雨滴、聚光灯、闭合到黑场的圆圈。<br>· 道具和文字：今今的礼帽、打字机字条、橡皮印章、索引卡、图钉、红线。<br>· 讲解件：把候选词概率条做成"嫌疑人名单"。<br>· 后期：老电影的划痕、灰尘、闪烁和上下黑边。 |
| `music.py` | 爵士 noir 配乐和全部卡点音效。输出 `out/music.wav` 和 `out/sync.npz`。 |
| `render.py` | 分镜，约 50 个镜头。 |
| `cover.py` | 16:9 和 3:4 两张封面。 |

```bash
python3 music.py                        # 约 40 s
python3 render.py --still 18.5 54.3     # 抽帧，输出到 out/stills/
python3 render.py --range 52 62         # 片段预览
python3 cover.py                        # 封面
python3 render.py                       # 整片：out/我不知道_Hallucination.mp4（4 核约 1 小时）
```

## 一句话

今今什么都答得上来，直到它给念念编了一篇不存在的论文。它学会了说"我不确定，我们一起查"；后来在组会上，念念也说出了那句"我不知道"。

## 转场和卡点音效

每个转场都写在 `cues.TRANS` 里。`render.py` 按它决定镜头怎么进场，`music.py` 按它放对应的音效，所以画面和声音不会对不上。其余切换都是落在拍子上的硬切，切入时镜头轻推一下。

| 转场 | 用在 | 画面（`core/timeline.py`） | 声音（`core/synth.py`） |
|---|---|---|---|
| iris | 新的一天、组会开场、drop2 结尾 | 圆形遮罩从一点打开；开场那次在镜头里画，能连天空一起盖住 | `aperture`，光圈的机械声 |
| lens | 钻进今今的"脑内"、进搜索结果 | iris 加镜框，画面从放大状态落回原位 | 玻璃嗖声、高音闪光、快门 |
| blinds | 查无此文、证据板、念念的本子、天亮 | 9 条百叶窗页片从上往下依次打开 | `shutter_ratchet`，每条页片一声咔嗒 |
| wipe | 写 memory、第二次组会、最后一页本子 | 斜边从左往右扫过 | 低沉的 `whoosh` |
| whip | 甩镜快剪 | 横向甩出加动态模糊 | `whoosh`，最响的一刻落在切点上 |
| 圆圈收拢 | 第一天结束、骤停、片尾 | `scene.iris_close`，圆圈收拢到黑场 | `aperture` |

画面里的事件也都卡在拍子上：

- 打字机字幕每个十六分音符打一个字，行尾响一声铃。
- 印章落在拍子上，配 `stamp_thud` 加画面一震。
- 闪电是两次闪光，配 `thunder`。
- 线索卡在 4 个拍子上依次掉落，配 `string_snap` 和纸张声。
- 证据卡按拍子钉上墙，配 `pin_tick`。
- 嫌疑人名单滚动时有老虎机声，指认时"叮"一声。如果大家一样可疑，这一声会更低、更犹豫。
- drop 段每个底鼓，镜头都轻轻顶一下。

## 画面上的事实

所有概率条和候选词都是示意，不对应真实数字。

- **Anthropic, Claude Platform Docs, "Reduce hallucinations"**（2026-10 核对）：
  - 允许 Claude 说"我不知道"，可以明显减少错误信息。
  - 让它先摘出原文、每句给出处，找不到依据就撤回那句。
  - 这些办法能减少幻觉，但不能完全消除。
- **OpenAI, "Why language models hallucinate"**（2025-09）：
  - 幻觉和"预测下一个词"的训练方式有关。
  - 现有的训练和打分常常奖励猜测，而不是承认不确定。
  - 冷门、零散的事实更容易出错。

片中的论文（林某 等，《睡眠与记忆的三阶段模型》，《脑与学习》第 87 页）、检索结果、角色和对话都是虚构的，片尾有声明。
