# 会算数的马 · 过拟合（Overfitting）

157 秒的无配音概念短片，1920×1080 / 60fps。一帧一理（quiet_concept）第 3 集，也是第一集用「卡点」做法：
画面和音乐共用一张卡点表 `cues.HITS`，`check_hits.py` 证明每个卡点的声音和画面落在同一帧。

| 文件 | 作用 |
|---|---|
| `cues.py` | 104 BPM、68 小节；段落、每小节一句的字幕（`LINES`）、卡点表（`HITS`，154 个）、真静默（`SILENCES`）、换场 |
| `music.py` | 配乐：每个卡点名都有声音；马蹄是有音高的（C D E F G），静默连混响尾巴一起归零 |
| `check_hits.py` | 读 `out/sync.npz`，每个卡点和声音的偏差（目标 0 帧），有偏差就退出 1 |
| `render.py` | 分镜；同名卡点在不同段落重复出现，所以 `since/pop/count` 都带 `lo`（从第几小节起算） |
| `cover.py` | 封面：`COVER=A`（片中问句）或 `COVER=B`（「它答对了 89% 的题，靠的是看脸」，发布用这一版） |

```bash
python3 music.py && python3 check_hits.py                  # 154 hits, worst offset 0 frames
python3 render.py --still 29.1 47.5 65.8 81.7 110.3 137.3  # 抽帧 → out/stills/
python3 cover.py && COVER=B python3 cover.py
python3 render.py                                          # 整片 → out/会算数的马_CleverHans.mp4
../../../../../sm publish clever_hans
```

## 事实来源

- Pfungst, O. (1907/1911). *Clever Hans (The Horse of Mr. von Osten)*：马能看见知道答案的提问人时答对约 89%（50/56），看不见时约 6%（2/35）；线索是数到答案时提问人头部的轻微上抬。
- 1904 年 9 月，Carl Stumpf 牵头的 13 人委员会结论是没有作弊（据 Pfungst 书中的记述）。
- Lapuschkin, S. et al. (2019). Unmasking Clever Hans predictors and assessing what machines really learn. *Nature Communications*, 10, 1096：在 PASCAL VOC 2007 上训练的分类器认「马」依赖约五分之一马图上的来源水印，水印贴到汽车图上就判成马。

曲线、分数（100 / 38）、照片和水印样式是示意，片尾写明了；水印文字是通用的「© PHOTO ARCHIVE」，没有用真实机构名。
