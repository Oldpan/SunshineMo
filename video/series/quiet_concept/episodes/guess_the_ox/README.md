# 787 人猜牛（群体智慧）· 一帧一理 07

50s 扁平卡通风格（lemo `midcentury-toon`）：色块印得错一点版、线条会呼吸会断、一场一个底色、星芒和太阳光、奖章和小标签、色块翻页和圆形转场。配乐是酷爵士：颤音琴、拨弦低音、鼓刷、响指。
100 BPM，F 大调，55 小节，132 秒，366 个卡点。

```bash
./fonts.sh                                    # 一次：下载 OFL 字体到 ~/.local/share/fonts/toon
python3 music.py && python3 check_hits.py     # 366 hits, worst offset 0 frames
python3 render.py --still 26 57 69 76 98 114
python3 render.py && python3 cover.py && COVER=B python3 cover.py
```

## 史实

- Galton, *Vox Populi*, Nature 75 (1907)：1906 年普利茅斯牲畜展，六便士一张票，787 张可用纸条，中间值 1207 磅，宰后净重 1198 磅。高尔顿当年 84 岁。后人重读手稿得出中位数 1208，片中用发表的数字。
- Lorenz et al., PNAS 108 (2011)：苏黎世联邦理工 144 名学生，6 道瑞士估算题，按准确度给钱，猜 5 轮；看到别人答案后答案收拢、平均没变准、信心变高（原文 "confidence effect"）。
- Wang et al., *Self-Consistency*（谷歌，arXiv 2022 / ICLR 2023）：PaLM 540B 在 GSM8K 上 56.5% → 74.4%（40 次采样多数投票）。
- Vul & Pashler, Psychological Science 19 (2008)：同一个人两次猜测的平均比第一次准，隔三周再猜效果更大。后续复现结果不一，片中只说「常常」。
- 图表（点阵、两组实验的点、投票卡片的答案、1100/1260 两次猜测）都是示意。

## 经验

- 人物的脚要离字幕卡 60 px 以上；字幕卡在 y 990。
- 侧脸人物的胡子只画看得见的一侧：后脑一圈白发、一侧络腮胡、鼻下一撮八字胡。两边对称的椭圆会像耳罩。
- 标签里有中文就别用 slab 字体（Alfa Slab One 没有中文，会变方框）。
- 爆炸贴、飞纸条的终点先排位置表，再看静帧，别压住别的纸条和标题。
